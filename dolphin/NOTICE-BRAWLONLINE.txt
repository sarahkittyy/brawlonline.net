Brawl Online: Dolphin
=====================

dolphin/ is Brawl Online's Dolphin fork. It is developed in this repository; changes to it
go to this repository's main branch.

Our fork is based on Brawlback's Project-Plus-Dolphin (https://github.com/Brawlback-Team/Project-Plus-Dolphin.git),
which is based on Dolphin (https://github.com/dolphin-emu/dolphin). It was imported here on
2026-10-08 without its earlier history; the upstream base commits at that import:
  origin/rollback: merge-base b7d3413e8520f940255bbd83fe79938151914075 ("Checkin")
  origin/master: merge-base f1b4345d0854f1c4e5e8eb683237a771c6de5456 ("Merge pull request #14755 from JoshuaVandaele/cmakeupd-qt-useless-dlls")

The history of both lives in those repositories.

Brawlback's code here (Source/Core/Core/Brawlback/, including TimeSync.cpp and the
brawlback-common headers under include/) and its changes to Dolphin are by the Brawlback team
(https://github.com/Brawlback-Team): WhiteTPoison, PiNE (FaultyPine), Kapedani (ilazoja),
eliasreid, rapito, Believer1 and others; see the README's Credits. Include/gekkonet is GekkoNet by
HeatXD (its own LICENSE).

License: Dolphin is GPL-2.0-or-later (see COPYING and LICENSES/); our changes are under the
same license. Third-party code under Externals/ keeps its own licenses (Externals/licenses.md).

Submodules under Externals/ are pinned to upstream commits;
run "git submodule update --init --recursive" after cloning.

Not included: game data that Project-Plus-Dolphin keeps in its tree, i.e. the
Brawl save template (Data/Sys/NetplaySave/, Data/user/Wii/title/) and the Project+ launcher
.dol binaries (Data/user/Launcher/*.dol). The launcher takes these from the user's own
Project+ files.
